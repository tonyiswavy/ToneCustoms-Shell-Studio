# Shell Studio status

The repository now contains the standalone Windows editor application and implemented foundations for architectural scene objects, a visual grid/scene viewport, selectable objects, XYZ numeric transforms, snapping, save/load, autosave, crash recovery, project snapshots, undo/redo, multi-floor services, measurements, room/trim/opening helpers, DDS inspection and material validation, texture import classification, GTA/custom prop indexing and placement metadata, imported-model inspection, collision generation, scene bounds, walk/lighting preview state, performance/optimization analysis, validation/safe autofix, Blender/Sollumz/CodeWalker dependency checks, headless Blender scene generation, bridge logs, GTA-output verification, FiveM resource staging/install validation, update metadata, tests and automatic Windows builds.

## Not finished yet

The application must not be represented as complete yet. Remaining production work includes a true GPU-backed perspective 3D renderer with mouse camera/gizmos, real wall-opening CSG and stair meshes, full material-browser UI and DDS conversion/compression, a populated GTA prop database/browser UI, robust GLB/FBX/OBJ mesh import into the editor, exact Sollumz operator integration for GTA drawable/collision/bounds export, verified CodeWalker inspection automation where supported, installer/update UX, and end-to-end FiveM in-game validation. Final export must stay blocked or clearly failed when GTA conversion output is absent.
