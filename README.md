> **Project status: In development / planning.** This repository currently contains a project README describing intended functionality. It does **not** currently provide an installable Windows application, verified build, or public release. Features below represent development targets, **not completed capabilities**.

## Vision

A standalone Windows application intended to simplify FiveM interior-shell creation and preparation, with a visual workflow designed around the Blender, Sollumz and CodeWalker ecosystem.

## Target workflow

**Create → Build → Texture → Place Props → Validate → Export → Test in FiveM**

## Planned features

- Visual shell viewport for construction and inspection
- Walls, floors, ceilings, rooms, openings and stairs
- Transform controls; project save/load; undo/redo
- Material and texture workflows, including DDS where appropriate
- GTA/custom prop placement and validation
- Preparation of collision/bounds and FiveM resource structure
- Workflow integrations with Blender, Sollumz and CodeWalker
- Windows build and update architecture

**None of these features should be interpreted as production-ready unless a verified release explicitly confirms them.**

## Quality standard before an official release

A completed end-to-end flow must be validated: prepare a shell, use supported materials/props, export the resource, load it on a FiveM test server, and verify geometry, textures and collision. Known blocking issues must be resolved or clearly disclosed.
